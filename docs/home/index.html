Welcome to the Epic Remastered project

This is an unofficial project that reworks and extends the third edition of Games Workshop’s Epic game system, Epic 40,000.

Epic Remastered is by fans, for fans, and open to the community as a collaborative effort.

Date of this build: 2025-11-16

Developmental state

This project is now well under way, but we still have lots to do. For more information on this, see Development of this publication.

Content

Main project

The content components for the game are as follows:

  • Home: This home page for HTML outputs, frontmatter for PDF outputs, and other content that does not belong in one of the more specific components.

  • Core: The main body of the project, principally the core rules of play. This component is now functionally complete, but there are still improvements we’d like to make and details to attend to. Among other things, we need to create and add more graphics and images — especially where explanatory examples are concerned.

  • Battles: Rules for setup and scenarios, plus ideas for campaign play. We’ve populated many of the topics that we need with good drafts, but there are still some empty placeholder topics at present.

  • Armies: Guidance on how to choose and build your armies, along with army lists that detail detachments, unit data sheets and points costs for each faction in the game. There is almost no content in this component at present — but fear not, you’ll find army lists in the interactive Detachment Builder.

We also have a content component for project contributors:

  • Contributor’s Guide: Guidance for contributors, to help with governance and consistency, and to document our methods in a transparent way.

Detachment Builder

Also important to the project, but residing in an entirely separate codebase and hosting environment from the main project:

  • Epic Remastered Detachment Builder: A convenient way to choose your army online and to print out your detachments and unit data sheets. Ian Wood continues to adapt and extend this from the open source 'Army Forge' software to suit our needs, and to populate it with new and revised content. We intend to mirror the Detachment Builder content in the Armies component eventually.

Aside from the above links, you can also find all these items in one or more of the navigation menus.
